# Keystroke Dynamics Dissertation

MSc Applied Cyber Security project evaluating the robustness of keystroke dynamics for continuous authentication using participant-specific One-Class SVM models.

The study evaluates authentication performance across multiple sessions, fixed, semi-fixed and free-text tasks, and conditions of human variability.

## Repository contents

'main_pipeline.py' – Data processing, feature extraction, Fisher score analysis, model preparation, hyperparameter tuning and OCSVM evaluation.
'run_experiments_dissertation.py' – Runs the experimental configurations reported in the dissertation.
'requirements.txt' – Python dependencies required by the analysis pipeline.

## Data availability

Participant keystroke data and participant-level output files are not included in this public repository due to privacy and ethical considerations. The behavioural data collected during the study were pseudonymised rather than made fully anonymous.

The complete project materials have been provided separately through the University submission system for assessment.
