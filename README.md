# Keystroke Dynamics Dissertation — Code Submission

This repository contains the full implementation used to produce the results
reported in Chapter 4 (Findings) of the dissertation _"Evaluating the
Robustness of Keystroke Dynamics for Continuous Authentication: A
Multi-Session Study Under Conditions of Human Variability."_

## Contents

| File                              | Purpose                                                                                                                                                       |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `main_pipeline.py`                | Core implementation: data loading, participant filtering, feature extraction, Fisher score ranking, hyperparameter tuning, and OCSVM training and evaluation. |
| `run_experiments_dissertation.py` | Defines and runs the nine experiments reported in the dissertation.                                                                                           |
| `make_confusion_matrices.py`      | Generates the confusion matrix figures presented in Chapter 4.                                                                                                |
| `requirements.txt`                | Python package dependencies.                                                                                                                                  |
| `input/`                          | Contains the clean keystroke event export used as the pipeline's input.                                                                                       |
| `dissertation_outputs/`           | Generated by running the pipeline; contains all results referenced throughout Chapter 4.                                                                      |

## Requirements

- Python 3.10+
- Dependencies listed in `requirements.txt`

## How to Run

```
pip3 install -r requirements.txt
python3 run_experiments_dissertation.py
python3 make_confusion_matrices.py
```

The first command runs all nine experiments end to end — feature extraction,
Fisher score ranking, a 192-combination hyperparameter search per experiment,
and final model training and testing. This takes approximately 1.5 hours
depending on the host machine, given the size of the search grid.

The second command generates the confusion matrix figures from the saved
results of the first run.

## The Nine Experiments

| Experiment name                          | Purpose                                           |
| ---------------------------------------- | ------------------------------------------------- |
| `fixed_normal_across_sessions`           | Fixed-text robustness across Sessions 3–5         |
| `semi_fixed_normal_across_sessions`      | Semi-fixed text robustness across Sessions 3–5    |
| `free_normal_across_sessions`            | Free-text robustness across Sessions 3–5          |
| `fixed_normal_to_rushed`                 | Fixed-text model tested against rushed typing     |
| `fixed_normal_to_distracted`             | Fixed-text model tested against distracted typing |
| `fixed_normal_updated_through_session_3` | Fixed-text enrolment extended to Session 3        |
| `fixed_normal_updated_through_session_4` | Fixed-text enrolment extended to Session 4        |
| `free_normal_updated_through_session_3`  | Free-text enrolment extended to Session 3         |
| `free_normal_updated_through_session_4`  | Free-text enrolment extended to Session 4         |

Each experiment produces its own folder under `dissertation_outputs/experiments/`,
containing:

| File / folder                      | Contents                                                                    |
| ---------------------------------- | --------------------------------------------------------------------------- |
| `experiment_results.csv`           | Summary authentication results by test session — source of Tables 4.3–4.7   |
| `feature_fisher_score_ranking.csv` | Full 67-feature Fisher ranking — source of Figures 4.1–4.3 and Table 4.1    |
| `model_tuning_validation.csv`      | Full 192-combination hyperparameter search results — source of Table 4.2    |
| `selected_model_features.csv`      | The final feature list selected for that experiment's model                 |
| `claim_scores/`                    | Every individual authentication attempt, with raw model scores              |
| `participant_metrics/`             | Per-participant authentication results, not just pooled figures             |
| `model_details/`                   | Per-participant record of features actually used and training sample counts |

`dissertation_outputs/shared/` contains the feature tables (`sample_features.csv`,
`free_text_window_features.csv`) used across all experiments, along with
`participants_selected.csv`, recording which participants met the five-session
inclusion criterion.

## Data and Privacy

The `input/` folder contains the anonymised keystroke event export, identified
only by participant code. Consistent with the data protection approach
described in Section 3.2, no file in this repository links a participant code
to a real name or other identifying information; that mapping was collected
separately, for study administration only, and is not part of this codebase.
